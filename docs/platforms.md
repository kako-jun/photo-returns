# PhotoReturns — 対応プラットフォーム

---

## 現在リリース済み: デスクトップ版

PhotoReturns のデスクトップ版は、Windows / macOS / Linux の3OSに対応している。

| OS | 配布形式 | 備考 |
|----|----------|------|
| Windows | 実行ファイル（.exe） | ダウンロードしてそのまま起動 |
| macOS | アプリケーションバンドル（.app） | ダブルクリックで起動 |
| Linux | AppImage / .deb / .rpm | 環境に合わせた形式を選択 |

インストール作業は不要。ダウンロードしたファイルを実行するだけで使い始められる。

---

## デスクトップ版の特徴

### 完全ローカル動作

ネットワーク通信を行わないため、インターネット接続がなくても利用できる。
外付けHDDやNASへの整理も、オフライン環境でも問題なく動作する。

### OS標準のフォルダ選択

フォルダの指定は、各OSの標準的なダイアログを通じて行う。
OSの使い勝手をそのまま活かせる。

### テーマの自動切り替え

ダークモード / ライトモードはOSの設定に自動的に追従する。
システム全体の外観設定を変えるだけで、アプリの見た目も切り替わる。

---

## 将来の対応予定: モバイル版

スマートフォンはそもそも写真が生まれる場所であり、デスクトップに転送する手間なく端末上で直接整理できることには大きな意味がある。

モバイル版の実現は、PhotoReturns の長期目標のひとつに位置づけられている。

| OS | 状況 |
|----|------|
| Android | 将来のリリースで対応予定 |
| iOS | 将来のリリースで対応予定 |

モバイル版では、端末内のストレージを直接操作し、写真を別フォルダや外部ストレージへ整理・コピーする形を想定している。

---

## 各プラットフォームでの哲学的一貫性

デスクトップ版であれ、将来のモバイル版であれ、PhotoReturns の中核にある考え方は変わらない。

- ネットワーク通信なし
- ローカルストレージ上で完結
- 完全無料・課金なし
- 整理後のファイルはどのアプリでも開ける標準的な構造

どのプラットフォームで使っても、ユーザーは自分の写真の完全なコントロールを持ち続ける。
