# PhotoReturns — 使い方

---

## 基本の流れ

PhotoReturns の操作は3ステップで完結する。

1. **フォルダを選ぶ** — 整理したい写真のある場所と、保存先を指定する
2. **スキャンしてプレビューする** — 処理内容を確認してから進む
3. **実行する** — ボタン一つで整理が完了する

---

## ステップ 1: フォルダの選択

画面上部で2つのフォルダを指定する。

| 項目 | 説明 |
|------|------|
| 入力フォルダ | 整理したい写真・動画が入っているフォルダ |
| 出力フォルダ | 整理後のファイルを保存するフォルダ |

各ボタンをクリックすると、OSの標準的なフォルダ選択画面が開く。

**注意事項:**

- 出力フォルダが入力フォルダの中にある場合 → エラーが表示され処理は行われない（無限ループ防止）
- 入力フォルダと出力フォルダが同じ場合 → 上書きモードの警告が表示される

---

## ステップ 1.5: デフォルト設定の調整（任意）

スキャンの前に、写真と動画それぞれのデフォルト設定を調整できる。

| 設定 | 写真のデフォルト | 動画のデフォルト |
|------|----------------|----------------|
| 日付の取得元 | EXIFメタデータ | ファイル更新日時 |
| タイムゾーン | EXIFから自動取得 | なし |
| 回転補正 | EXIFに従う | なし |

変更しなければデフォルト値のまま処理される。

---

## ステップ 2: スキャンとプレビュー

「スキャン」ボタンをクリックすると、入力フォルダ内のすべてのメディアファイルが読み込まれ、画面下部にグリッドで一覧表示される。

### グリッドの見方

グリッドには11列の情報が表示される。

| 列 | 内容 |
|----|------|
| サムネイル | 小さなプレビュー画像。クリックで拡大表示 |
| 種別 | 写真 / 動画 のバッジ |
| 元のファイル名 | 変換前の名前 |
| 変換後のファイル名 | 整理後の名前（プレビュー） |
| 日付の取得元 | このファイルで使う日時ソース |
| 撮影日時 | 取得された撮影日時 |
| ファイルサイズ | ストレージ上のサイズ |
| 回転情報 | EXIFに記録された回転角度 |
| 補正前の向き | 補正前のプレビュー |
| 補正後の向き | 補正後のプレビュー |
| 操作ボタン | 行の展開 / 折りたたみ |

### 個別ファイルの調整

各行の展開ボタンを押すと、そのファイルだけの設定を個別に変更できる。

- 日付の取得元
- タイムゾーンオフセット
- 回転補正モード

デフォルト設定と異なる処理をしたいファイルだけ変更すればよい。

### フィルタ・ソート

グリッド上部でファイルの絞り込みや並び替えができる。
大量のファイルから特定のものを見つけたいときや、撮影日時順に確認したいときに使う。

---

## ステップ 3: 処理の実行

「処理 & リネーム」ボタンをクリックすると、グリッド内の全ファイルに対して整理処理が実行される。

処理中は各ファイルの状態がリアルタイムで更新される。

### 処理完了後

処理が終わると結果のサマリーが表示される。

| 項目 | 内容 |
|------|------|
| 成功したファイル数 | 正常に整理されたファイルの数 |
| スキップされたファイル数 | 重複として判定されスキップしたファイルの数 |
| 失敗したファイル数 | エラーが発生したファイルの数 |

失敗したファイルがある場合は、その行をクリックすると自動でスクロールして詳細を確認できる。
「Retry Failed Files」ボタンで失敗分だけ再試行することも可能。

すべての処理の詳細は「Show Logs」ボタンで確認できる。

---

## その他の操作

- **ダークモード / ライトモード**: OSの設定に合わせて自動的に切り替わる
- **トップに戻るボタン**: 大量ファイル表示時に先頭へ素早く戻れる
- **ウィンドウリサイズ**: ウィンドウサイズに合わせてレイアウトが自動調整される
