# PhotoReturns — 使い方

---

## 基本の流れ

PhotoReturns の操作は3ステップで完結する。

1. **フォルダを選ぶ** — 整理したい写真のある場所と、保存先を指定する
2. **スキャンしてプレビューする** — 処理内容を確認してから進む
3. **実行する** — ボタン一つで整理が完了する

---

## ステップ 1: フォルダの選択

画面上部で2つのフォルダを指定する。

| 項目 | 説明 |
|------|------|
| 入力フォルダ | 整理したい写真・動画が入っているフォルダ |
| 出力フォルダ | 整理後のファイルを保存するフォルダ |

各ボタンをクリックすると、OSの標準的なフォルダ選択画面が開く。

**注意事項:**

- 出力フォルダが入力フォルダの中にある場合 → エラーが表示され処理は行われない（無限ループ防止）
- 入力フォルダと出力フォルダが同じ場合 → 上書きモードの警告が表示される

---

## ステップ 1.5: デフォルト設定の調整（任意）

スキャンの前に、写真と動画それぞれのデフォルト設定を調整できる。

| 設定 | 写真のデフォルト | 動画のデフォルト |
|------|----------------|----------------|
| 日付の取得元 | EXIFメタデータ | ファイル更新日時 |
| タイムゾーン | EXIFから自動取得 | なし |
| 回転補正 | EXIFに従う | なし |

変更しなければデフォルト値のまま処理される。

また、写真・動画どちらにも属さない全体設定として「EXCLUDE SYSTEM ARTIFACTS」トグルがある。
Android/Google フォトで削除した写真が `.trashed-*` として残っていたり、端末が生成したサムネイル
（`.thumbnails`）やOSの管理ファイル（`.DS_Store` など）が紛れ込んでいたりする場合、これらを
「あなたの写真ではない」ものとして自動でスキャン対象から除外する。既定でON。オフにすると、
削除済みファイルやサムネイルも含めてすべて取り込む。

さらに「PROVENANCE TAG」欄と「USE FOLDER NAME IF LABEL EMPTY」トグルがある。複数のソース
（Google Takeout / LINE 保存分 / 別端末など）から写真を1つのフォルダへ集約するとき、出力
ファイル名にどこから来たかのタグを残せる。PROVENANCE TAG にラベル（例 `takeout`）を入力
すると、スキャンする全ファイルにそのタグが付く（例 `2025-04-22_20-59-15_takeout.jpg`）。
ラベルを空のままにして USE FOLDER NAME IF LABEL EMPTY を ON にすると、代わりにファイルの
直上の親フォルダ名がタグとして使われる。どちらも指定しなければタグは付かない（既定）。

---

## ステップ 2: スキャンとプレビュー

「スキャン」ボタンをクリックすると、入力フォルダ内のすべてのメディアファイルが読み込まれ、画面下部にグリッドで一覧表示される。

### 除外されたファイルの確認

「EXCLUDE SYSTEM ARTIFACTS」がONの状態でシステム生成物が1件以上見つかった場合、ファイル数の隣に
「EXCLUDED: N」というバッジが表示される。押すと、どのルール（削除済み・サムネイルなど）に該当して
何件除外されたかの内訳と、除外されたファイルのパスの一部（サンプル）を確認できる。
除外が無かった場合はバッジ自体が表示されない。

### グリッドの見方

グリッドには11列の情報が表示される。

| 列 | 内容 |
|----|------|
| サムネイル | 小さなプレビュー画像。クリックで拡大表示 |
| 種別 | 写真 / 動画 のバッジ |
| 元のファイル名 | 変換前の名前 |
| 変換後のファイル名 | 整理後の名前（プレビュー） |
| 日付の取得元 | このファイルで使う日時ソース |
| 撮影日時 | 取得された撮影日時 |
| ファイルサイズ | ストレージ上のサイズ |
| 回転情報 | EXIFに記録された回転角度 |
| 補正前の向き | 補正前のプレビュー |
| 補正後の向き | 補正後のプレビュー |
| 操作ボタン | 行の展開 / 折りたたみ |

iPhone などの HEIC/HEIF、AVIF もスキャン対象に含まれ、撮影日時・向き・サイズは他の形式と
同様に読み取れる。ただしサムネイル・拡大表示は環境（OSのwebview）によって表示できないことが
あり、その場合はレイアウトを崩さず拡張子名のプレースホルダに切り替わる。なおこれらの形式は
無劣化での回転処理に対応していないため、回転は行われない（EXIF情報を使った整理自体は行われる）。
これに合わせて回転列のドロップダウンも「NO ROTATE (FMT)」表示で無効化され、補正後の向き列にも
回転は当たらない（回るように見えて実際は回らない、という不一致を避けるため）。

### 個別ファイルの調整

各行の展開ボタンを押すと、そのファイルだけの設定を個別に変更できる。

- 日付の取得元
- タイムゾーンオフセット
- 回転補正モード

デフォルト設定と異なる処理をしたいファイルだけ変更すればよい。

### フィルタ・ソート

グリッド上部でファイルの絞り込みや並び替えができる。
大量のファイルから特定のものを見つけたいときや、撮影日時順に確認したいときに使う。

---

## ステップ 3: 処理の実行

「処理 & リネーム」ボタンをクリックすると、グリッド内の全ファイルに対して整理処理が実行される。

処理中は各ファイルの状態がリアルタイムで更新される。

### 処理完了後

処理が終わると結果のサマリーが表示される。

| 項目 | 内容 |
|------|------|
| 成功したファイル数 | 正常に整理されたファイルの数 |
| 失敗したファイル数 | エラーが発生したファイルの数 |

失敗したファイルがある場合は、その行をクリックすると自動でスクロールして詳細を確認できる。
「Retry Failed Files」ボタンで失敗分だけ再試行することも可能。

すべての処理の詳細は「Show Logs」ボタンで確認できる。

---

## その他の操作

- **ダークモード / ライトモード**: OSの設定に合わせて自動的に切り替わる
- **トップに戻るボタン**: 大量ファイル表示時に先頭へ素早く戻れる
- **ウィンドウリサイズ**: ウィンドウサイズに合わせてレイアウトが自動調整される
